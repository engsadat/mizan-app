# Org Chart Integration into Mizan — Design Spec

**Date:** 2026-08-26  
**Scope:** Add organizational chart reports to Mizan app, serve pre-generated region-specific charts with PDF export  
**Status:** Design approved

---

## Overview

Integrate existing organization chart reports (4 region-specific charts) into Mizan's Reports section. Users can view org charts by region and export to PDF.

**Approach:** Script-based generation (matches employee/project data workflow)
- Adapt existing `gen_org_chart.py` to read from Mizan's database
- Run script to generate 4 HTML files once (manual trigger)
- Serve HTML files + PDF export via Flask routes
- No real-time sync — charts update only when script runs

---

- **Server location:** `/home/southMizan/sources/`
  - `emp_sort.xlsx` — job sort order/ranking

## Architecture

### 1. Script: `scripts/gen_org_charts.py`

**Responsibility:**
- Read Employee, Project data from Mizan's database
- Read supporting Excel files from `/home/southMizan/sources/`
- Generate 4 region-specific HTML files
- Write to `app/static/org_charts/`

**Inputs:**
- Mizan database (via Flask app context)
- `emp_sort.xlsx` — job sort order
- `Office-RE.xlsx` — RE directory info

**Outputs:**
- `app/static/org_charts/09_OrgChart_Asir.html`
- `app/static/org_charts/10_OrgChart_Jizan.html`
- `app/static/org_charts/11_OrgChart_Baha.html`
- `app/static/org_charts/12_OrgChart_Najran.html`

**Run:** 
```bash
python scripts/gen_org_charts.py
```

---

### 2. Routes (in `app/blueprints/reports/routes.py`)

#### Landing Page
```
GET /reports/org-chart
→ Template: org_chart_landing.html
→ Display: 4 region cards (Asir, Jizan, Baha, Najran)
```

#### View Org Chart
```
GET /reports/org-chart/<region>
  - region: asir | jizan | baha | najran
→ Template: org_chart_view.html
→ Display: HTML content from org_charts/<region>.html
→ Include: "Export PDF" button
```

#### PDF Export
```
GET /reports/org-chart/<region>/pdf
→ Use Playwright to render HTML → PDF
→ Return: downloadable file
  Filename: OrgChart_<Region>_<YYYY-MM-DD>.pdf
  Example: OrgChart_Asir_2026-08-26.pdf
```

## Update Workflow

### Manual Trigger
1. Admin runs: `python scripts/gen_org_charts.py`
2. Script reads from database + supporting Excel files
3. Outputs 4 HTML files to `app/static/org_charts/`
4. Charts appear updated in Mizan when refreshed

### No Real-Time Sync
- Org charts are **static** once generated
- Changes to Employee/Project data → visible only after script re-runs
- Charts do NOT auto-update on database changes

### Supporting Files Location (Server)
- Path: `/home/southMizan/sources/`
- Files: `emp_sort.xlsx`, `Office-RE.xlsx`
- Script reads from this location during generation

---

## Error Handling

### Missing HTML File
- Route tries to load `app/static/org_charts/09_OrgChart_Asir.html`
- If file not found → render friendly message:
  ```
  "الهيكل التنظيمي غير متوفر — يرجى تشغيل السكريبت أولاً"
  (Org chart not available — please run the script first)
  ```

### PDF Generation Failure
- If Playwright render fails → log error + show message:
  ```
  "فشل إنشاء ملف PDF — جرب طباعة المتصفح بدلاً من ذلك"
  (PDF creation failed — try browser print instead)
  ```

### Script Execution Failure
- If script fails to run → admin sees error
- Solution: check file paths, database connection, Excel file existence
- Fallback: guide admin to run manually with debug output

## PDF Export Specs

**Tool:** Playwright (headless browser rendering)
- Render HTML → PNG/PDF
- Keep Cairo font rendering

**Filename Pattern:** `OrgChart_<Region>_<YYYY-MM-DD>.pdf`
- Example: `OrgChart_Asir_2026-08-26.pdf`

**Page Format:** A3 Landscape (same as original HTML)
- Width: 420mm
- Height: 297mm

**Print Styles:** Embedded in HTML (generated by `gen_org_charts.py`)
- Margins: 14mm (left/right), 10mm (top/bottom)
- No extra footer/header added by PDF export
